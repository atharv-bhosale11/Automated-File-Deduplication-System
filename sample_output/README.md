# Sample Output

This directory contains sample outputs generated by the **Automated File Deduplication System**.

## Purpose

The files in this folder are included to demonstrate the functionality and expected results of the application.

## Demonstrated Features

- Duplicate file detection
- File checksum comparison using MD5 hashing
- Identification of redundant files
- Automatic duplicate file removal
- Storage optimization reporting
