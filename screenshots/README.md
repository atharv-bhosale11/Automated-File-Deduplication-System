# Project Screenshots

This directory contains screenshots demonstrating the execution and functionality of the **Automated File Deduplication System**.

## Included Screenshots

| Screenshot | Description |
|------------|-------------|
| `execution.png` | Shows the application running from the command line. |
| `duplicate_detection.png` | Displays duplicate files detected during the scanning process. |
| `duplicate_removal.png` | Demonstrates successful removal of duplicate files. |

## Purpose

These screenshots provide visual proof of:

- Recursive directory scanning
- Duplicate file detection using MD5 hashing
- Automatic duplicate file removal
- Command-line execution workflow

## Note

Screenshots are included for demonstration and portfolio purposes to showcase the project's functionality and results.
