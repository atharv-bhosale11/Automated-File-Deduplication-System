# Source Code

This directory contains the core implementation of the **Automated File Deduplication System**.

## Contents

| File | Description |
|------|-------------|
| `file_deduplicator.py` | Main Python script responsible for detecting and removing duplicate files using MD5 hashing. |

## Responsibilities

- Scan directories recursively
- Generate MD5 checksums for files
- Detect duplicate files
- Display duplicate file information
- Remove redundant copies
- Report deleted files

## Note

This folder contains only the application source code. Refer to the main repository README for installation instructions, project overview, and usage details.
